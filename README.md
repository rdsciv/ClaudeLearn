## Quick Start

```bash
git clone https://github.com/rdsciv/ClaudeLearn.git
cd ClaudeLearn
node learn.mjs
```

No dependencies required — just Node.js (v18+).

## What's Inside

### 8 Interactive Lessons

| #  | Lesson                          | Track               |
|----|---------------------------------|----------------------|
| 01 | What is Claude Code?            | Foundations           |
| 02 | Getting Started & First Commands| Foundations           |
| 03 | Exploring & Understanding Code  | Core Skills           |
| 04 | Writing & Editing Code          | Core Skills           |
| 05 | Debugging Like a Pro            | Core Skills           |
| 06 | Git & Version Control           | Workflows             |
| 07 | Planning Before Building        | Workflows             |
| 08 | Building for Impact             | Making a Difference   |

### Features

- **Quizzes** — Test your knowledge after every lesson with instant feedback
- **XP & Leveling** — Earn points, level up, get bonus XP for perfect scores
- **Badges** — Unlock titles: Launcher, Builder, Debugger, Architect, Changemaker
- **Learning Streaks** — Track consecutive days of learning
- **Playground** — Hands-on challenges to try with Claude Code
- **Impact Ideas** — Real project ideas for building software that helps people
- **Persistent Progress** — Your XP, level, and badges save between sessions

## Requirements

- [Node.js](https://nodejs.org/) v18 or later
- A terminal that supports ANSI colors (most modern terminals do)

## Usage

```bash
# Start the learning experience
node learn.mjs

# Navigate with keyboard:
#   01-08  Select a lesson
#   P      Playground challenges
#   I      Impact project ideas
#   Q      Quit
```

## What is Claude Code?

[Claude Code](https://docs.anthropic.com/en/docs/claude-code) is an agentic AI coding assistant by Anthropic that lives in your terminal. It can read your codebase, write and edit code, run commands, and help you build real software through natural conversation.
